## 0.9.0 - 2026-11-06

### Changed

* Name the set and the key of the config file in the errors about an invalid
  set, e.g. `set 'Bank 1': inputdir is empty` instead of `InputDir is empty`.
  The errors about an unusable `outputdir` name the set and the directory
* Report why each format rejected a file whose format cannot be detected, one
  line per format below `cannot deduce format`. The new function
  `parser.Detect` returns this error, which wraps `parser.ErrUnknownFormat`
* Rename the API of the package `parser` to idiomatic Go names, which breaks
  callers: `GetParser` is now `New` and returns an error for an unsupported
  format, `GetSourceFormats` is `SourceFormats`, and the methods `GetFormat`
  and `GetNumberOfEntries` of `Parser` are `SourceFormat` and `Len`. Use
  `Detect` instead of the removed `GetGuessedParser`
* Resolve relative paths in the config file, e.g. `inputdir: finance/inbox`,
  relative to the directory of the config file instead of the current working
  directory, so that `batch-convert` uses the same directories no matter from
  where it is started, e.g. by cron

### Fixed

* Report the line of a malformed value as the line in the file, as shown by a
  text editor. Empty lines and fields spanning several lines were not counted,
  e.g. for Comdirect and DKB exports the reported line was too small. A
  malformed CSV file now reports its line in `ParseError.Line` as well
* Bump github.com/xuri/excelize/v2 from 2.11.0 to 2.11.1
* Bump golang.org/x/text from 0.42.0 to 0.43.0
* Bump github.com/alecthomas/kong from 1.16.1 to 1.17.0
* Bump goreleaser/goreleaser-action from 7.2.3 to 7.3.0
* Bump DavidAnson/markdownlint-cli2-action from 24.2.0 to 25.0.0
