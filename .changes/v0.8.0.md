## 0.8.0 - 2026-10-10

### Added

* Barclaycard: take the payee of card payments (type `Belastung`) from the
  column `Beschreibung`, which now holds the name of the payee. It is taken
  over as it is

### Changed

* Reject a config file in which the `outputdir` of one set is the `inputdir` of
  another set. The converted files are no supported source format, so
  `batch-convert` failed on them in every later run
* Replace the Makefile with a Taskfile for [Task](https://taskfile.dev). Run
  `task` instead of `make`

### Fixed

* Do not reject sets in the config file as duplicates whose input directory and
  glob pattern only result in the same text when put together, e.g. `/finance`
  with `a*` and `/financea` with `*`
* Do not write a header line to the HomeBank CSV output files. HomeBank skips a
  header line on import, but shows a warning about it. The output files now
  contain data lines only
* Reject sets in the config file as duplicates which use the same input
  directory, one without `fileglobpattern` and one with `*`, as both read the
  same files
